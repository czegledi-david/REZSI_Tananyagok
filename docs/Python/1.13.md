# Év végi algoritmizálási feladatok

A következő feladatok az alapvető programozási logikát tesztelik. Minden feladatot egy önálló függvényként kell megírni, amely paraméterben kapja meg a bemenetet, és `return` segítségével adja vissza a kért eredményt. A főprogramban (a függvényen kívül) mindig hívd meg a megírt függvényt, és kezdd is valamit a visszakapott értékkel (például írasd ki a képernyőre)!

### 1. Legnagyobb szám keresése
Írj függvényt, amely egy számlistát kap paraméterként, és visszaadja a lista legnagyobb elemét. Ne használd a beépített `max()` függvényt, oldd meg egy ciklussal! A főprogramban hívd meg a függvényt egy teszt listával, és írasd ki a képernyőre a visszakapott értéket!

??? success "1. Feladat megoldása"
    ```python
    def legnagyobb_szam(lista):
        legnagyobb = lista[0]
        for szam in lista:
            if szam > legnagyobb:
                legnagyobb = szam
        return legnagyobb
        
    eredmeny = legnagyobb_szam([12, 5, 89, 23])
    print("A legnagyobb szám:", eredmeny)
    ```

### 2. Pozitív számok összege
Készíts egy függvényt, amely egy listát kap, benne pozitív és negatív számokkal. A függvény csak a pozitív számokat adja össze, és térjen vissza ezzel az összeggel. A program végén hívd meg a függvényt, és az eredményt közvetlenül a `print()` parancson belül jelenítsd meg!

??? success "2. Feladat megoldása"
    ```python
    def pozitiv_osszeg(lista):
        osszeg = 0
        for szam in lista:
            if szam > 0:
                osszeg += szam
        return osszeg
        
    print("A pozitív számok összege:", pozitiv_osszeg([-5, 10, 3, -2, 8]))
    ```

### 3. Szöveg megfordítása
Írj egy függvényt, amely egy szöveget kap bemenetként. A függvény cikluson keresztül építsen fel egy új szöveget, amely az eredeti visszafelé olvasva, majd adja vissza azt. Hívd meg a függvényt egy tetszőleges szóval, és írasd ki a visszakapott, megfordított szöveget!

??? success "3. Feladat megoldása"
    ```python
    def szoveg_megforditasa(szoveg):
        forditott = ""
        for betu in szoveg:
            forditott = betu + forditott
        return forditott
        
    forditott_szo = szoveg_megforditasa("programozas")
    print("Visszafelé:", forditott_szo)
    ```

### 5. Magánhangzók eltávolítása
Írj függvényt, amely egy szöveget kap paraméterként. Adjon vissza egy olyan új szöveget, amiből hiányzik az összes magánhangzó (a, e, i, o, u). Próbáld ki a függvényt egy saját mondattal, és írasd ki a kapott eredményt!

### 6. Számok átlaga
Készíts függvényt, amely egy számlistát vár paraméterként, és kiszámolja a benne lévő számok átlagát (összeg osztva a darabszámmal). Ne használd a beépített `sum()` függvényt! Hívd meg a függvényt, és a visszatérési értéket jelenítsd meg a képernyőn!

??? success "6. Feladat megoldása"
    ```python
    def szamok_atlaga(lista):
        if len(lista) == 0:
            return 0
        osszeg = 0
        for szam in lista:
            osszeg += szam
        return osszeg / len(lista)
        
    atlag = szamok_atlaga([10, 20, 30, 40])
    print("A számok átlaga:", atlag)
    ```

### 7. Adott karakter megszámolása
Írj függvényt, amely két paramétert vár: egy szöveget és egy betűt. A függvény számolja meg és adja vissza, hogy hányszor szerepel a megadott betű a szövegben. Hívd meg a függvényt, és írasd ki a kapott számot!

??? success "7. Feladat megoldása"
    ```python
    def karakter_szamlalo(szoveg, keresett_betu):
        darab = 0
        for betu in szoveg:
            if betu == keresett_betu:
                darab += 1
        return darab
        
    betuk_szama = karakter_szamlalo("matematika", "a")
    print("Az 'a' betűk száma:", betuk_szama)
    ```

### 9. Minden második elem

### 11. Szám faktoriálisa
Írj egy függvényt, amely egy `n` egész számot kap. Számolja ki és adja vissza az `n` faktoriálisát egy ciklus segítségével (pl. 4 faktoriálisa: 1 * 2 * 3 * 4). Hívd meg a függvényt például az 5-ös számmal, és írasd ki az eredményt!

??? success "11. Feladat megoldása"
    ```python
    def faktorialis(n):
        szorzat = 1
        for i in range(1, n + 1):
            szorzat *= i
        return szorzat
        
    eredmeny = faktorialis(5)
    print("5 faktoriálisa:", eredmeny)
    ```

### 12. Egyszerű jelszó ellenőrző
Készíts függvényt, amely egy jelszót (szöveget) kap bemenetként. Adjon vissza `True`-t, ha a jelszó legalább 8 karakter hosszú ÉS szerepel benne egy felkiáltójel (`!`). Egyébként adjon vissza `False`-t. A függvény meghívása után egy elágazással (if) írd ki a képernyőre, hogy "Erős jelszó" vagy "Gyenge jelszó", a kapott logikai érték alapján!

??? success "12. Feladat megoldása"
    ```python
    def eros_jelszo(jelszo):
        if len(jelszo) >= 8 and "!" in jelszo:
            return True
        else:
            return False
            
    ha_eros = eros_jelszo("titkosjelszo!")
    if ha_eros:
        print("Erős jelszó")
    else:
        print("Gyenge jelszó")
    ```

### 15. Szóközök cseréje
Írj függvényt, amely egy mondatot kap szövegként. Cseréljen ki benne minden szóközt csillag (`*`) karakterre cikluson keresztül, és adja vissza az új szöveget! A `.replace()` függvény használata tilos. Hívd meg a függvényt egy tetszőleges mondattal, és írasd ki a módosított szöveget!

??? success "15. Feladat megoldása"
    ```python
    def szokoz_csillag(szoveg):
        uj_szoveg = ""
        for betu in szoveg:
            if betu == " ":
                uj_szoveg += "*"
            else:
                uj_szoveg += betu
        return uj_szoveg
        
    modositott = szokoz_csillag("Ez egy teszt mondat")
    print("Csillagozott szöveg:", modositott)
    ```

### 20. Tartalmaz-e nullát?
Készíts egy függvényt, amely egy számlistáról eldönti, hogy tartalmaz-e `0`-át. Ha igen, azonnal térjen vissza `True` értékkel, ha végigment a listán és nem talált, térjen vissza `False`-al! A függvényhívás eredményétől függően egy elágazással írd ki a képernyőre, hogy "Van benne nulla" vagy "Nincs benne nulla"!

??? success "20. Feladat megoldása"
    ```python
    def van_benne_nulla(lista):
        for szam in lista:
            if szam == 0:
                return True
        return False
        
    ha_van = van_benne_nulla([1, 5, 0, 8])
    if ha_van:
        print("Van benne nulla")
    else:
        print("Nincs benne nulla")
    ```
