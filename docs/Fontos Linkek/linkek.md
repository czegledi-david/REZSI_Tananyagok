# Szükséges Szoftverek és Letöltések

Az otthoni gyakorláshoz és a házi feladatok elkészítéséhez fel kell készítened a számítógépedet. Ezen az oldalon összegyűjtöttük az összes olyan hivatalos, ingyenes szoftvert, amit az órákon is használni fogunk.

*Kattints a programok neve alatti linkekre a hivatalos letöltőoldalak eléréséhez!*

---

## Kódszerkesztők és Fejlesztőkörnyezetek (IDE)

### 1. Visual Studio 2022 (Community Edition)
Ez a program a C# programozás és a Windows Forms asztali alkalmazások (GUI) fejlesztésének az alfája és ómegája. A szakmai vizsgán is ezt fogod használni.

* **Letöltés:** [visualstudio.microsoft.com/vs/community](https://visualstudio.microsoft.com/vs/community/)

!!! warning "Telepítési tipp!"
    A telepítő (Visual Studio Installer) elindítása után megjelenik egy rengeteg opciót tartalmazó ablak. **Mindenképpen pipáld be** az `.NET asztali fejlesztés` (.NET desktop development) dobozt, különben nem fogod tudni elkészíteni a vizsgafeladatokat!

### 2. Visual Studio Code (VS Code)
A világ legnépszerűbb, pehelysúlyú kódszerkesztője. Ezt fogjuk használni a Python, a HTML, a CSS és a JavaScript kódok megírásához. Nem keverendő össze a sima Visual Studióval!

* **Letöltés:** [code.visualstudio.com](https://code.visualstudio.com/)

!!! tip "Ajánlott bővítmények (Extensions)"
    Telepítés után a VS Code bal oldali sávjában (kockák ikon) érdemes feltenni a következő kiegészítőket: **Python** (Microsoft), **Live Server** (Ritwick Dey), és **Material Icon Theme** (a szép fájlikonokért).

## Programnyelvek

### Python
Ahhoz, hogy a VS Code megértse és futtatni tudja a Python kódodat, fel kell telepítened magát a nyelvet a számítógépedre.

* **Letöltés:** [python.org/downloads](https://www.python.org/downloads/) (Mindig a legújabb stabil verziót töltsd le!)

!!! danger "Kritikus telepítési lépés!"
    Amikor elindítod a Python telepítőjét, a legelső ablak legalsó sorában lesz egy ilyen négyzet: **`[ ] Add Python.exe to PATH`**. Ezt **KÖTELEZŐ bepipálni** a telepítés megkezdése előtt! Ha ezt elfelejted, a VS Code nem fogja megtalálni a Pythont a gépeden.

## Adatbázisok és Webszerver

### XAMPP
A weboldalak és az adatbázisok fejlesztéséhez elengedhetetlen. A XAMPP egyetlen kattintással feltelepít a gépedre egy Apache webszervert és egy MySQL (MariaDB) adatbázis-szervert, ráadásul tartalmazza a phpMyAdmin felületet is az adatbázisok kényelmes kezeléséhez.

* **Letöltés:** [apachefriends.org/download](https://www.apachefriends.org/download.html) (Válaszd a legújabb PHP verziót tartalmazó csomagot!)

!!! info "Hogyan használd?"
    Telepítés után keresd meg a `XAMPP Control Panel` programot. Az adatbázisok futtatásához az **Apache** és a **MySQL** sorok melletti `Start` gombra kell kattintanod. Ha mindkettő zöldre vált, a böngésződbe a `http://localhost/phpmyadmin` címet beírva éred el az adatbázisokat.
